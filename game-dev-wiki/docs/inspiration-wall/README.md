# 灵感墙 (Inspiration Wall) 🚀

一个功能丰富、高度还原 Milanote 体验的轻量级卡片式灵感墙与画布整理工具。

## ✨ 核心特性体系

### 1. 🗂️ 结构化管理与嵌套
- **无限层级嵌套文件夹**：创建文件夹与子文件夹，支持多主题归类。
- **Milanote Column 卡片列容器**：支持多卡片纵向嵌套堆叠、顶部色彩强调线、一键整列联动拖拽。
- **画板快捷入口卡片 (Board Link)**：直接在画布中放置通往其他子画板的应用卡片，显示统计数据与快捷跳转。

### 2. 🧰 左侧创作工具箱 (Milanote Sidebar)
- 📝 **便签笔记 (Note)**：富文本编辑、高对比度中划线、标题字号、10色调色板与8色便签主题。
- 🗂️ **分组列 (Column)**：卡片嵌套容器，可在列内自由添加与管理子笔记/待办。
- ☑️ **待办清单 (To-do)**：交互式复选框、完成划线动效、支持回车快速新增任务项。
- 🖼️ **图片卡片 (Image)**：支持本地图片转码上传（离线持久化）或网络图片 URL，带下方说明文字。
- 🎬 **视频卡片 (Video)**：支持 B站 (Bilibili BV号 / 链接) 嵌入播放、YouTube 嵌入或 MP4 视频直链。
- 🔗 **网页书签 (Link)**：带域名徽章、标题与摘要的外链跳转卡片。
- 🎨 **色卡卡片 (Color Swatch)**：Pantone 风格色卡，带拾色器、色号名称与 HEX 显示。
- 🔤 **独立大标题 (Heading)**：画板区域大字标题，无背景极简排版。

### 3. 🎯 交互与体验
- **高对比度黑边指针**：画布抓取与平移手型带有清晰黑白描边，在纯白画布下永不迷失。
- **面包屑路径导航**：实时展示当前层级位置，支持快速上卷回退。
- **纯原生前端无依赖**：无需 Node.js 或构建工具，双击 `index.html` 即可直接运行，数据基于浏览器 LocalStorage 离线自动持久化保存。

## 🛠️ 技术栈

- HTML5
- Tailwind CSS (CDN)
- Phosphor Icons (矢量图标库)
- Vanilla JavaScript (ES6+)
- LocalStorage API & FileReader API
