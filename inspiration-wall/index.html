静默导出为 data.json 推荐 ⭐

一键下载 data.json 并放入项目根目录。推送到 GitHub 后，手机打开网址将自动默认呈现你的全部画板！

GitHub Gist 私有云静默实时同步 全自动

绑定 GitHub Personal Access Token (PAT) 后，在电脑上每次编辑画板都会在后台静默自动同步到你的私有 Gist，手机端输入相同 Token 自动实现多端实时无缝更新！

本地离线备份与恢复

将当前全部画板数据导出为 .json 文件保存在本地，或者通过导入历史备份文件进行快速覆盖恢复。
